# NewFinder

独立的 macOS 文件管理器（菜单栏常驻），Chrome 式多标签 + Finder 路径栏，可接管系统 Finder 的「打开文件夹 / 在 Finder 中显示」。

面向 **macOS 13+**（Apple Silicon / Intel）。

## 下载

在 [Releases](https://github.com/yikeshu0611/NewFinder/releases) 下载最新 `NewFinder-x.x.x.dmg`，拖入「应用程序」即可。

**当前版本：1.1.6**

## 主要功能

### 界面与导航
- **Chrome 式标签页**：多标签浏览、关闭、三击标签分离为新窗口
- **路径栏**：面包屑分段导航（点击 `>` 展开子目录菜单）、⌘L 编辑路径并补全
- **访问历史**：路径栏左侧下拉，快速回到最近访问目录
- **复制路径**：路径栏按钮或 **⌘⇧C**
- **列表视图**：异步加载大文件夹、图标缓存、列排序、文件夹展开大纲、拖放移动/复制
- **界面缩放**：齿轮菜单内 30%–500% 调节（滚轮步进 1%）

### 文件操作
- 打开、**打开方式**（全部应用三栏列表 + 勾选设为默认）、重命名（F2）、**赋予修改权限**、拷贝 / 剪切 / 粘贴、移到废纸篓
- 剪切项灰色显示；改名/拷贝/剪切/粘贴/删除成功后工具栏绿色 ✓ 反馈
- **压缩 / 解压**：右键 `压缩…`、`解压…`、`打开压缩包`（内建；支持 ZIP / TAR.GZ，解压另含 rar/7z 等若已安装 unar）
- 双击压缩包在 NewFinder 标签页中浏览内容
- **快捷新建**：固定项（文件夹 / txt / docx / pptx / xlsx）与自定义类型均可在设置中管理；可勾选「展示在工具栏」、可删除（固定项名称不可改，删除后可恢复）
- xlsx / docx / pptx 为有效 Office 空白模板
- 新建后自动选中并进入重命名
- **重名处理**（新建 / 粘贴）：`未命名` → `未命名 副本` → `未命名 副本 2`…；粘贴 `foo 副本 3` → `foo 副本 4`
- 重命名时 **⌘A** 全选文件名（不会全选列表）；回车确认后保持选中

### 收藏夹
- 路径栏星标收藏当前目录
- 工具栏收藏夹分组（**按住拖动排序**），点击展开书签列表
- 支持多分组、右键重命名 / 删除

### Finder 接管（可选）
- 菜单栏图标常驻（不占 Dock）
- 拦截系统 Finder：打开文件夹、Chrome「在文件夹中显示」等转到 NewFinder
- 退出 UI 后 **Watch 后台** 仍在：点击 Dock Finder 时自动拉起
- NF 已运行时点击 Finder **只前置窗口**，不重复开 Desktop 标签
- 首次需在 **系统设置 → 隐私与安全性 → 自动化** 允许控制 Finder

### 设置
- 登录时启动、是否拦截 Finder
- **额外新建类型**：仅编辑固定项以外的扩展名
- **检查更新**：按钮旁显示当前版本号，从 GitHub Releases 检测并下载 DMG
- 书签与收藏夹顺序持久化

## 构建

```bash
./build.sh
open build/NewFinder.app
```

产物：`dist/NewFinder-1.1.6.dmg`

## 快捷键

| 快捷键 | 作用 |
|--------|------|
| ⌘L | 编辑路径 |
| ⌘⇧C | 复制路径 |
| ⌘↑ | 上层文件夹 |
| ⌘[ / ⌘] | 后退 / 前进 |
| ⌘N | 新建窗口 |
| ⌘T | 新建标签页 |
| ⇧⌘N | 新建文件夹 |
| F2 | 重命名 |
| ⌘. | 显示 / 隐藏隐藏文件 |
| ⌘W | 关闭标签或窗口 |

## 系统要求

- macOS 13.0 或更高
- Finder 拦截需要「自动化」权限
